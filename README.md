# Vocab Lab · 英语生词积累与智能复习系统

一套**完全离线**的英语生词管理系统：**录入生词 → 生词库归档 → 卡片记忆（艾宾浩斯曲线自动排期）→ 生词检测（意思匹配等）→ 用教材/考纲单词生成文章和阅读题**。

打开方式：**双击 `index.html`**（推荐 Chrome / Edge）。不需要联网、不需要安装、不需要构建步骤。

---

## 1. 五个核心能力（对应你的需求）

| 你要的功能 | 在哪里 | 怎么实现 |
|---|---|---|
| 录入生词就进生词库 | 生词库 | 单个添加 / 批量粘贴导入 / 从教材词表勾选；输入单词会自动查内置词库补全音标、词性、释义、例句 |
| 每个生词库都有自己的归档 | 归档 | 每个词库**彼此独立**：自己的生词、复习记录、已掌握/已归档清单、检测记录、生成过的文章、导出备份 |
| 卡片记忆 | 卡片记忆 | 翻卡 + 四级评分（忘记/模糊/认识/太简单），键盘操作，自动朗读 |
| 按艾宾浩斯曲线自动出现 | 卡片记忆 / 总览 | 学完一个词后按 **5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天** 十个节点自动排期，到期才会出现在复习队列里 |

| 背完单词做生词检测 | 生词检测 | 词义匹配（连线式配对）、中英选择、拼写填空、听音选词、混合检测；成绩自动写回复习计划 |

## 2. 快速开始

**打开方式（任选一种，建议固定用一种）**

* 最简单：双击 `index.html`（Chrome / Edge）。
* 想同时用手机 / iPad：双击 `一键启动（含手机访问）.bat`，它会启动服务器并打开浏览器，终端里会显示手机可用的局域网地址。

> 注意：`file://`（双击打开）和 `http://127.0.0.1:5180`（用 bat 打开）在浏览器里算**两个不同的站点**，
> 各自存一份数据。所以请固定用同一种方式打开，否则会看到「空的生词库」。
> 需要换方式时，先导出备份，再在新方式里导入。

1. 打开后按下面顺序使用：
2. 点「**生词库 → ＋ 添加生词**」输入生词，或点「**批量导入**」粘贴一批，或点「**从教材/考纲选词**」直接勾选。
3. 点「**卡片记忆 → 今日待复习**」开始背；翻卡看释义后按 `1 2 3 4` 评分。
4. 背完点「**生词检测 → 开始检测**」做一次检测，错题会自动回到复习队列。
5. 点「**文章阅读 → 本地生成**」，立刻得到一篇用你选的词写成的文章和阅读题（不联网也能用）。

### 键盘快捷键

| 按键 | 作用 |
|---|---|
| `空格` / `Enter` | 翻卡（正面 ↔ 背面） |
| `1` `2` `3` `4` | 忘记 / 模糊 / 认识 / 太简单 |
| `S` | 朗读当前单词 |
| `/` | 跳到搜索框 |

## 3. 艾宾浩斯复习机制

### 3.1 十个复习节点

新词学完后，每个词都会沿着固定的十个节点往前走，**每答对一次前进一格**：

```
5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天 → 已掌握
```

四种评分对排期的影响：

| 评分 | 记忆阶段 | 下次出现 |
|---|---|---|
| 忘记 | 回到起点（0） | 默认 1 分钟后重新出现（同一轮里还会再练一遍） |
| 模糊 | 退一格 | 当前节点间隔的一半 |
| 认识 | 前进一格 | 下一个节点的间隔 |
| 太简单 | 前进两格 | 对应节点的间隔 |

走完第 10 个节点后，这个词会被标记为**已掌握**（默认自动移入归档，可在设置里关掉）。

### 3.2 可自定义

「设置与备份 → 复习节奏」里可以逐个修改这 10 个节点，也可以一键切换：

* **经典艾宾浩斯**（默认，5 分钟起）
* **宽松**（适合长期，10 分钟起、最长 180 天）
* **紧凑**（适合考前突击，1 分钟起、最长 15 天）

还能设置：每日新词上限、忘记后重新出现的间隔、掌握后是否自动归档、卡片是否自动朗读、是否使用反向卡片（看中文想英文）。

### 3.3 看得见的排期

总览页会显示：未来 7 天的复习量柱状图、记忆强度分布（刚起步/初步记住/比较牢固/接近掌握/已掌握）、最近 13 周的学习热力图、连续学习天数。

## 4. 生词库与归档

### 4.1 多生词库

左下角可以建立任意多个生词库（比如「七年级下册 Unit 3」「中考高频」「错词本」），点「＋」新建，点名字切换。每切换一个词库，下面的所有内容都跟着切换：

生词列表 · 复习队列与记忆阶段 · 归档 · 检测记录 · 生成过的文章 · 导出备份

### 4.2 归档页

每个词库的归档包含：

* **已掌握**：走完十个节点的词（可一键恢复）
* **手动归档**：暂时不想再复习的词（可一键恢复）
* **检测记录**：每次检测的时间、题型、范围、得分、用时、错题清单
* **文章记录**：生成过的每一篇文章，可重新打开重做题目
* **词库导出**：单个词库导出为 JSON，可以拷到别的电脑导入

### 4.3 生词列表能做什么

搜索（英文/中文都能搜）、按状态筛选（全部/学习中/待复习/没学过/易错/已掌握/已归档）、按最近添加/字母/下次复习/记忆阶段/错误次数排序、批量选择后归档/恢复/移动到其他词库/删除、导出 JSON 或 CSV（CSV 带记忆数据，可用 Excel 打开）。

## 4.4 上传自己的词表（支持多种文件格式）

「生词库 → ＋ 批量添加 → 或者选文件」，可以一次选**多个文件**，也可以直接把文件**拖进输入框**。全部在本机读取，不上传任何东西：

| 格式 | 说明 |
|---|---|
| `.xlsx / .xlsm` | **Excel 表格**，自动读第一个工作表；序号列和表头行（单词/词性/中文…）会自动跳过 |
| `.docx` | Word 文档，按段落读成一行行单词 |
| `.csv / .tsv` | 逗号 / 制表符分隔，**自动识别 UTF-8 / GBK / UTF-16 编码**（Excel 导出的中文 CSV 常是 GBK，不会乱码） |
| `.txt / .md` | 纯文本 / Markdown，一行一个词，或「单词 释义」都行 |
| `.json` | 词表 JSON（`{"words":[...]}`）或本应用导出的备份 |
| 图片 | 走「拍照识词」（见下） |
| `.xls / .doc` | 旧版二进制格式不支持，请另存为 `.xlsx / .docx` 或 `.csv` |
| `.pdf` | 不能直接读词，建议把那页截图后用「拍照识词」 |

读进来之后都会进入同一张预览表格：自动补释义、可勾选、可手改，再一次性入库。

## 4.5 拍照识词与真人发音

### 拍照识词

「生词库 → 📷 拍照识词」：用手机对着单词表 / 课本词汇页拍一张，或从相册选图，然后点识别：

| 方式 | 需要什么 | 能读什么 |
|---|---|---|
| **用 AI 识别图片** | 设置里配好 AI 接口 + 支持看图的模型（如 gpt-4o） | 中英对照的单词表能一次读全，**包括中文释义和词性** |
| **用本地 OCR 识别英文** | 不需要账号；第一次联网下载识别引擎（约 11MB，之后可离线） | 只认英文单词，中文释义由内置词库自动补 |

识别结果会直接填进「批量添加」的预览表格，可以勾掉不要的词、补上缺的释义，再一次性入库。

### 真人发音

默认为**真人发音优先**：单词朗读走有道的真人录音（联网时使用），句子或断网时自动回落到系统语音。

「设置与备份 → 发音」里可以：

* 切换 **自动（真人优先） / 只用真人 / 只用系统语音**
* 选 **美音 / 英音**
* 点「试听真人发音」「试听系统语音」直接对比
* 挑选系统语音（带 ★ 的是更像真人的 Natural / Neural / Siri 这类语音）

> iPhone / iPad 上想更好听：设置 → 辅助功能 → 朗读内容 → 声音 → 英语 → 下载 Siri 声音（或 Alex），再回到应用里选中它。

## 5. 录入生词的三种方式

### 5.1 单个添加

输入单词时会自动查内置词库，把音标、词性、释义、例句一起填好（可以随意修改）。保存后可以连续添加下一个。

### 5.2 批量添加（推荐）

「生词库 → ＋ 批量添加」：**一行一个单词粘进去就行**，点「识别并预览」，系统会先查好中文意思、词性、音标，然后在一张表格里列给你看：

* 查到的词自动填好；查不到的词留空，**直接在表格里手写**
* 已经在词库里的词会自动标成「已收录」并**默认不勾选**，不会重复添加
* 勾选/取消勾选任意行，最后点「加入生词库」一次性入库（几百个词也没问题）
* 配了 AI 接口的话，可以点「用 AI 补全缺的释义」一次补全几十个

支持的写法（可以混用、行首的「1.」「①」会自动去掉）：

```
apple                                    ← 只写单词（自动查中文）
banana 香蕉                              ← 空格分隔
careful, adj., 仔细的, ˈkeəfl            ← 逗号分隔（单词,词性,释义,音标）
| happy | adj. | 高兴的 |                ← Markdown 表格
garden                                   ← 单词一行、释义下一行也认
花园
```

查词顺序：**① 内置词库（1300+ 核心词）→ ② 你自己录过的所有生词 → ③ AI（可选）**。所以同一本书里的词，你补过一次释义，之后再录就会自动带出来。
也可以直接选文件（`.txt / .csv / .md / .json`）。

### 5.3 从教材 / 考纲词表选词

「从教材/考纲选词」里可以按册次勾选单词，一键加入当前生词库：

* 一键「全选」「全不选」「只选还没收录的」
* 已经在这个词库里的词会标上「已收录」，不会重复添加

## 7. 文章阅读 + 阅读理解题

### 7.1 本地生成（离线，默认）

不联网也能用。做法是：内置 9 个精心设计的主题模板（校园生活、周末旅行、环境保护、健康生活、志愿服务、科技与生活、家庭与朋友、动物与自然、城市与生活），每个模板的每个空位都有**词性 + 语义 + 语法**三重约束（例如「地点」只会填 park / museum / village 这类能说 "go to the ..." 的词，「形容老师」只会填 friendly / patient 这类词），再从你选的词表里挑词填进去。

生成结果包含：

* 一篇 80–120 词的短文（主题、难度可选）
* **细节理解题**（模板配套，带中文解析）
* **词义猜测题**（"The word X is closest in meaning to ___"）
* **选词填空题**（从文章里挖空，同词性干扰项）
* **生词表**：文章里用到的每个词都能点开看释义、朗读，并一键加入生词库

提交答案后自动评分，答错的词会按艾宾浩斯规则重新排进复习计划。

### 7.2 AI 生成（可选）

在「设置与备份 → AI 文章生成」里填写 **Base URL + 模型名 + API Key**，就能用「AI 生成」让大模型写更自然、更贴近考试的文章和题目。

* 兼容 OpenAI 接口格式的服务（OpenAI、DeepSeek、通义、智谱、各类中转服务等都行，填对应的 Base URL 即可）
* 点「测试连接」可以先验证配置
* Key 只保存在**这台电脑的浏览器**里，不会上传到别处
* AI 不可用时会自动回退到本地生成，不影响使用

> 注意：浏览器直接调用大模型接口需要对方允许跨域（CORS）。如果测试连接失败，多半是服务端没开 CORS，可以换一个支持浏览器直连的服务，或者把 Base URL 指向你自己的中转地址。

## 8. 生词检测

五种题型，范围可选「已到期 / 易错词 / 所有学习中 / 全部生词」，题量 10 / 20 / 30 / 全部：

| 题型 | 玩法 |
|---|---|
| **词义匹配** | 左边单词、右边释义，点一个单词再点它的释义，5 个一组，配错了会提示正确答案 |
| **中英选择** | 「英 → 中」或「中 → 英」，四选一 |
| **拼写填空** | 给中文释义和首字母提示，把单词拼出来；有「提示」按钮（多给一个字母，判为「模糊」） |
| **听音选词** | 听发音，从四个单词里选 |
| **混合检测** | 上面三种随机出现 |

检测结果：

* 得分、正确率、用时、分题型统计
* **错题本**：「只重做错题」可以立刻再练一遍
* 结果自动写回复习计划：**答对 → 进入下一个节点；答错 → 回到起点，约 1 分钟后重新出现**

## 9. 数据、备份与多设备

所有数据（生词、复习记录、检测、文章、设置）都保存在**本机浏览器**的 localStorage 里，不联网、不上传。

* 「设置与备份 → 导出全部备份」得到完整 JSON
* 「归档 → 导出这个词库」只导出当前词库（含检测与文章记录）
* 「导出 CSV」得到带记忆阶段/复习次数/下次复习时间的表格
* 导入时如果词库重名，会自动加「（导入）」，不会覆盖现有数据

**换电脑、换浏览器或清理浏览数据之前，记得先导出备份。**

### 9.1 在 iPad / 手机上用

页面是纯静态的（HTML + CSS + JS），iPad 的 Safari 完全能跑，触摸和 Apple Pencil 都支持；朗读按钮需要点一下才会发声（iOS 的要求）。窄屏下侧栏会收成抽屉，点左上角 `☰` 展开。

**注意**：iPad 上不能直接双击 `index.html`（Safari 不允许本地页面加载同目录的其它文件）。两种方式：

**方式一（推荐）：放到静态托管**

把整个 `vocab-lab` 文件夹上传到 GitHub Pages / Netlify Drop / Vercel / 对象存储等任意静态托管，用手机浏览器打开后「分享 → 添加到主屏幕」，之后就是全屏 App。项目自带 `manifest.webmanifest` 和 `sw.js`，**联网打开过一次之后断网也能继续用**。

**方式二：电脑当服务器**

```bash
node tools/serve.js 5180
```

终端会打印两个地址，第二个是给 iPad 用的：

```
本机:  http://127.0.0.1:5180/index.html
同网段设备（iPad / 手机）: http://192.168.x.x:5180/index.html
```

## 11. 修改与自检

### 11.1 自检


## 12. 已知限制

* 朗读依赖系统语音：Windows 上一般自带英文语音，Linux 可能需要在系统里装语音包。
* AI 生成需要目标服务允许浏览器直连（CORS）；不配置也完全不影响其他功能。
* 本地生成是「模板 + 受约束选词」，句子结构固定，胜在**完全离线、语法可靠、可无限生成**；想要更多样的文风请用 AI 生成。
* 数据存在浏览器里，换设备请用备份文件迁移。
